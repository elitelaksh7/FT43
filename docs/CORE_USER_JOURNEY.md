## Core User Journey — Instant Analysis Flow

1. **Scan a receipt**
   - Use the OCR Bill Scanner to capture a receipt. The app extracts items, totals, taxes, and merchant details instantly.

2. **Quick confirmation**
   - A simple modal presents the parsed data with two actions:
     - "Confirm & Close" to save immediately
     - "See Impact" to jump into a focused view of how this purchase affects budgets and trends

3. **Mini-dashboard view**
   - A compact dashboard opens with:
     - AI Nudge Cards tailored to this purchase (e.g., category suggestions, budget tips, recurring pattern detection)
     - Focused charts showing category impact, monthly trends, and remaining budget

4. **AI learns and adapts**
   - If you adjust the category or merchant, the AI Categorization Engine learns from your correction to improve future suggestions.

5. **Real-time updates**
   - Analytics and budgets update instantly via WebSockets, keeping the main dashboard and insights in sync without page reloads.
